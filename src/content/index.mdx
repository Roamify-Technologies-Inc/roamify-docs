# Roamify API Documentation

Welcome to the Roamify API documentation. This guide helps you authenticate, choose the correct environment, and integrate Roamify services into your product.

Roamify API is a REST API that allows you to buy eSIMs, manage eSIM lifecycle events, check partner balance, and work with exchange rates.

Currently, we support the following services:

- [Authentication](/authentication)
- [eSIMs](/esims/overview)
- [Exchange Rates](/exchange-rates/overview)
- [Health Check](/health)

If you need access or support, use the [Roamify Partner Portal](https://partner.getroamify.com/sign-up) or email [support@getroamify.com](mailto:support@getroamify.com).

## Getting Started
If this is your first time using Roamify API, follow the steps below:

1. Sign up or sign in via [Roamify Partner Portal](https://partner.getroamify.com/sign-in).
2. Get your Access Token from `API Keys`.
3. Pick your API environment:
  - Development: `https://api-dev.getroamify.com`
  - Production: `https://api.getroamify.com`
4. Read [Authentication](/authentication), then start with [eSIMs](/esims/overview).

We have two environments for our API:

- **Development**: Use this environment to test your integration with Roamify API.

  Endpoint: `https://api-dev.getroamify.com`

- **Production**: Use this environment when you are ready to go live with your application.

  Endpoint: `https://api.getroamify.com`
